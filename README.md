#  FS-XML Interpreter (FS-XML v1.2)

A Python / PySide6 GUI application for automated and secure application of code modifications generated by AI models (ChatGPT, Claude, DeepSeek, etc.) adhering to the **FS-XML v1.2** specification.

---

##  Why is this project needed? (Problem & Solution)

### Problem:
When developing software with AI assistants, developers regularly face tedious routine tasks:
1. **Manual Copy-Pasting:** AI outputs code snippets for 5 different files. You have to manually open each file, locate the correct code section, and paste it in.
2. **Risk of Breaking Code:** It's easy to make mistakes during copy-pasting, omit brackets, or overwrite critical functions.
3. **Difficult Rollbacks:** If the AI-suggested code fails to work, manually reverting changes across multiple files is tedious and time-consuming.
4. **System File Safety:** AI might accidentally rewrite configuration or system files that should remain untouched.

### Solution:
**AI Code Custom Interpreter** completely addresses these issues:
- **Automated Application:** AI outputs instructions in XML format (`FS-XML`), and the app creates new files or applies precise partial edits with 1 click.
- **Safe Context & Access Control:** You choose which project files are writable (`[WRITABLE]`) and which are protected from modifications (`[READ_ONLY]`).
- **Context Dump Generator:** The app bundles selected project files into a single, clean text dump accompanied by instructions for the AI model.
- **1-Click Rollbacks & History:** All modifications are recorded in a local SQLite database. Any change session can be instantly rolled back to the disk's prior state.
- **Manual Edit Protection:** If you modify a file manually after applying AI changes, the system warns you before attempting a rollback.

##  Key Features

1. **Project & Context Manager:**
   - Manage multiple projects simultaneously.
   - Tree-view file & folder picker with flexible access controls:
     - 🟢 `Writable (W)` — Files can be created and edited.
     - 🟡 `Read-Only (RO)` — Read-only files (AI sees them as context, but cannot modify them).

2. **Context Dump Generation (`context_dump.txt`):**
   - Automatic bundling of selected project files into a single document alongside FS-XML v1.2 instructions.
   - Automatic skipping of binary files (images, `.pyc`, `.exe`) and protection against encoding errors.

3. **FS-XML Parser & Executor:**
   - Support for `<fs_create>` (file creation) and `<fs_edit>` tags (partial replace with `<fs_search>`/`<fs_replace>` or full overwrite with `<all />`).
   - **Path Traversal Protection:** Prevents escaping the project root folder (protects against paths like `../../`).
   - Write-permission verification prior to executing any file modification.

4. **Execution History & Rollbacks:**
   - Full storage of operations and original file snapshots in SQLite.
   - **"Rollback"** button to restore the state BEFORE XML execution.
   - **"Apply Again"** button to re-apply rolled back changes.
   - Detection of manual edits made on top of AI changes.

##  FS-XML v1.2 Format (Overview)

AI models generate instructions using the following formats:

### 1. Creating a new file
```xml
<fs_create path="src/utils/logger.py">
import datetime

def log(msg):
    print(f"[{datetime.datetime.now()}] {msg}")
</fs_create>
```

### 2. Partial file modification (Search & Replace)
```xml
<fs_edit path="src/utils/logger.py">
<fs_search>
def log(msg):
    print(f"[{datetime.datetime.now()}] {msg}")
</fs_search>
<fs_replace>
def log(msg, level="INFO"):
    print(f"[{datetime.datetime.now()}] [{level}] {msg}")
</fs_replace>
</fs_edit>
```

### 3. Full file overwrite
```xml
<fs_edit path="config.py">
<fs_search><all /></fs_search>
<fs_replace>
DEBUG = True
DATABASE_URL = "sqlite:///app.db"
</fs_replace>
</fs_edit>
```
