# Документация тестов Backend (Python)

Тесты написаны с использованием фреймворков `pytest` и `httpx`.

## Структура проверок:
1. `test_sandbox.py`:
   - Защита от выхода за пределы директории (Path Traversal / `../`).
   - Нормализация относительных путей (слэши Windows/POSIX).
   - Проверка разграничения прав доступа (Writable / Read-Only / Unmarked).
2. `test_commands.py`:
   - Создание файлов (`<fs_create>`) с проверкой на коллизии (запрет перезаписи).
   - Изменение файлов (`<fs_edit>`): точечный поиск и замена, поиск с нечувствительностью к пробелам в концах строк, полная перезапись через `<all />`.
   - Управляющие команды (`<fs_profile_create>`, `<fs_file_state>`) с проверкой флага `allow_management`.
3. `test_context_and_ignore.py`:
   - Проверка правил двухуровневого игнора (синтаксис `.gitignore`).
   - Исключение директорий из обхода без зависаний.
   - Детекция бинарных файлов (замена на заглушку).
   - Сборка контекстного дампа с флагом неотмеченных файлов и без него.
   - Проверка опции `ignore_tests` (детекция файлов `test_*` и `*_test`, пометка отмеченных тестовых файлов как существующих без содержимого и исключение неотмеченных тестов).
4. `test_api.py`:
   - Интеграционные тесты REST API (создание проектов, переключение профилей, запуск патчей, получение истории).
5. `test_features_v2.py`:
   - Исправление бага игнора (проверка, что `test` не игнорирует `text.txt`).
   - Откат правок (`/records/{id}/rollback`) с детекцией ручных правок на диске (`manual_edited=True`) и форсированным откатом (`force=True`).
   - Жизненный цикл снапшотов (сохранение набора отмеченных файлов, восстановление на диск и удаление).
   - Удаление кастомных и дефолтных профилей с автосозданием `default`.
   - Поддержка inline-комментариев (`#`) и экранированного `\#` в `.fsignore`.
   - Откат отката (`/records/{id}/reapply`) и безопасный просмотр содержимого файлов (`/file-content`).
6. `test_config_and_folder.py`:
   - Сохранение JSON-конфигурации проекта (`fs_orchestrator_config.json`) в корневую папку (`/projects/{id}/config/save`).
   - Импорт конфигурации (`/projects/import-config`) с автоматическим созданием проекта, профилей и прав на файлы, а также обработка ошибок формата/отсутствия файла.
   - Открытие корневой папки проекта через API (`/projects/{id}/open-folder`).
   - Интеграционная проверка параметра `ignore_tests=true` в эндпоинте `/projects/{id}/dump`.
